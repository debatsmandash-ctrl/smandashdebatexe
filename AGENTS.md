# Architecture rules

- Shared node edits live in Lovable Cloud with Google-authenticated editor/admin roles; local storage is only a public read cache so edits appear in 3D, 2D, and Reading views.
- Selection trial records stay separate from permanent member/team records because temporary positions and scores must not become permanent roles.
- Offline app-shell caching is generated by vite-plugin-pwa and registered only through the guarded wrapper; preview and development never register it.
- Graph views are lazy-loaded independently so reading and lobby visits do not download the 3D engine; mobile rendering uses a device safety ceiling independent of persisted desktop settings.
